# 🔥 핫딜 큐레이션 사이트

토스쇼핑 쉐어링크 · 쿠팡 파트너스 링크를 올리는 **내 채널 웹사이트**입니다.
쉐어링크 "활동 채널 인증"에 제출할 주소가 되고, 딜을 올리면 카톡방에 붙여넣을 문구까지 만들어 줍니다.

**사이트 본체는 [`v2/`](./v2)** 입니다 — Next.js로 그리고, 딜은 **Supabase의 `deals` 표**에
들어갑니다. 설치·배포는 [v2/README.md](./v2/README.md)를 보세요.

이 문서는 그 사이트에 **딜을 올리고 관리하는 자동화**를 설명합니다.

- **`.github/`** — 이슈 폼 2개와 워크플로 4개
- **`scripts/`** — 워크플로가 실행하는 스크립트
- **`automation.json`** — 자동화 설정. 켜고 끄기, 조건, 훑을 커뮤니티 목록

> **v1(정적 HTML) 사이트**는 저장소 루트의 `index.html` · `about.html` · `add.html` ·
> `data/`에 그대로 남아 있지만 **더 이상 자동화가 건드리지 않습니다.** v2가 배포되면
> 지우거나 v2로 가는 안내 페이지로 바꾸세요. 그때까지는 GitHub Pages에서 옛 화면이
> 계속 보입니다.

---

## 1. 처음 한 번만 — 저장소에 열쇠 넣기

자동화는 GitHub Actions 안에서 Supabase에 직접 씁니다. 그래서 열쇠 두 개가 필요합니다.

저장소 → **Settings → Secrets and variables → Actions → New repository secret**

| 이름 | 값 | 어디서 |
|---|---|---|
| `SUPABASE_URL` | `https://xxxx.supabase.co` | Supabase → Project Settings → API |
| `SUPABASE_SERVICE_ROLE_KEY` | `service_role` 키 | 같은 화면의 **service_role** (anon 아님) |

> ⚠️ **`service_role` 키는 RLS를 통째로 건너뜁니다.** 저장소 Secrets 에만 두세요.
> `NEXT_PUBLIC_*` 에 넣거나 v2 앱 코드로 가져가면 그 순간 아무나 딜을 지울 수 있습니다.
> v2 앱은 지금처럼 anon 키만 쓰면 됩니다.

사이트 주소를 답글에 같이 받고 싶으면 **Variables** 탭에 `SITE_URL`(예:
`https://내사이트.workers.dev`)을 넣으세요. 없어도 동작합니다.

채널 이름·소개·수수료 고지 문구는 [`v2/src/lib/site.ts`](./v2/src/lib/site.ts)에서 고칩니다.

## 2. 딜 올리기 — 폰에서, 코드 없이

**GitHub 이슈에 쉐어링크만 붙여넣으면** 사이트가 알아서 갱신됩니다.

1. 저장소 → **Issues → New issue → 「딜 올리기」**
2. 쉐어링크 주소와 지금 가격만 넣고 제출 (상품명·이미지는 비워두면 링크에서 자동으로 가져옵니다)
3. 1분쯤 뒤 딜이 사이트에 뜨고, 이슈 답글로 **카톡에 붙여넣을 문구**가 옵니다.
   이슈는 자동으로 닫힙니다.

딜이 끝나면 **「딜 마감」** 이슈에 상품명 일부만 적으면 마감 처리됩니다.

알아 두실 것:

- **저장소 주인이 연 이슈에만 반응합니다.** 공개 저장소라 누구나 이슈를 열 수 있는데,
  이 조건이 없으면 남의 쉐어링크가 내 사이트에 올라갑니다 (`.github/workflows/deal.yml`).
- 같은 링크를 다시 올리면 새로 쌓지 않고 그 딜을 최신 정보로 되살립니다.
- 자동으로 가져오는 값은 링크 페이지의 OG 태그입니다. 쇼핑몰이 막아두면 못 가져오는데,
  그때는 실패로 끝내지 않고 "상품명을 직접 적어 달라"고 답글이 옵니다.
- **쉐어링크를 만드는 일 자체는 자동화할 수 없습니다.** 토스는 공개 API가 없어서
  앱에서 상품 공유 → 링크 복사까지는 사람이 해야 합니다. 그 뒤가 전부 자동입니다.
- **카톡방에 자동으로 쏘는 것도 불가능합니다.** 카카오는 오픈채팅에 봇이 글을 쓰는 공개
  API를 주지 않습니다. 문구를 만들어 주는 데까지가 한계이고, 붙여넣기는 사람이 합니다.

## 2-1. 컴퓨터에서 직접 올리기

v2 사이트의 **`/admin`** 화면에서 폼으로 올릴 수도 있습니다. 관리자 계정으로 로그인하면
같은 `deals` 표에 들어갑니다. 자세한 건 [v2/README.md](./v2/README.md).

## 2-2. 알아서 돌아가는 것들

`automation.json` 하나로 켜고 끕니다. 지금은 **토스 중심**이라 아래 두 개가 돌고,
쿠팡은 파트너스 최종승인 뒤에 켭니다.

### 딜 후보 찾기 — 매일 아침 (켜져 있음)

아침 8시 30분에 커뮤니티 핫딜 게시판의 공개 RSS를 읽어, 새 글 후보를
**「오늘의 딜 후보」 이슈 하나**로 보내 줍니다. 줄마다 **올리기** 링크가 붙어 있어서,
누르면 상품명이 이미 채워진 「딜 올리기」 폼이 열립니다. 토스 앱에서 그 상품을 찾아
쉐어링크를 복사해 넣고 가격만 적으면 끝입니다.

없어지는 건 "하루 종일 뒤지는 시간"입니다. 링크 복사는 여전히 사람 몫이고,
그건 토스에 공개 API가 없는 한 어쩔 수 없습니다.

- 출처마다 몫을 나눠 담으니 한 커뮤니티가 목록을 다 차지하지 않습니다.
- 첫 실행 뒤 **Actions → 딜 후보 찾기 → 요약**을 보면 어떤 RSS가 살아 있고 어떤 게
  막혔는지 줄줄이 나옵니다. ❌ 표시된 주소는 `automation.json`의 `scout.sources`에서
  지우거나 바꾸세요. 하나가 막혀도 나머지는 그대로 돕니다.
- 하루 한 번, 목록 페이지만 읽습니다. 각 사이트의 이용약관을 확인하고 쓰세요.
- 가격과 재고는 확인하지 않은 "후보"일 뿐입니다. 올리기 전에 직접 보세요.

### 가격 감시 · 자동 마감 (켜져 있음)

6시간마다 올려둔 딜의 링크를 열어 가격을 확인합니다. **오르면 마감, 품절이면 마감,
더 내려갔으면 사이트 가격도 따라 내립니다.** 확인에 실패한 딜은 건드리지 않습니다 —
모르는 것과 끝난 것은 다르니까요.

### 쿠팡 자동 게시 — 최종승인 뒤에 켜세요 (지금은 꺼짐)

쿠팡 파트너스 API는 **최종승인(누적 판매 15만원)된 파트너에게만** 열립니다.
승인 전에는 키를 발급받을 수 없어서 `automation.json`의 `coupang.enabled`를
`false`로 두었습니다. 워크플로는 그대로 있으니 승인되면 바로 켤 수 있습니다.

켜는 순서:

1. 쿠팡 파트너스 → Tools → 파트너스 API 에서 액세스 키 / 시크릿 키 발급
2. 저장소 Secrets 에 `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY` 등록
   (하위 채널을 나누려면 `COUPANG_SUB_ID`도)
3. `automation.json`의 `coupang.enabled`를 `true`로
4. Actions → 쿠팡 자동 게시 → Run workflow 로 한 번 돌려보기

켜면 하루 두 번 골드박스를 훑어, 조건에 맞는 상품을 **내 딥링크로 바꿔서** 올립니다.
제휴 링크로 못 바꾼 상품은 올리지 않습니다 — 수수료가 안 붙는 링크는 올릴 이유가 없습니다.
조건은 `coupang`의 최소 할인율·가격 범위·한 번에 올릴 개수·제외 키워드에서 바꾸세요.

## 3. 쉐어링크 활동 채널로 등록하기

토스 앱 → 쉐어링크 → **활동 채널을 알려주세요** 화면에서 배포된 v2 사이트 주소를 넣고
`채널 추가` → `제출`을 누릅니다.

인증은 "이 사람이 실제로 상품을 소개하는 채널을 운영하는가"를 보므로, 제출 전에
**딜 몇 개는 실제 링크로 올려두는 편이 안전합니다.** 채널 소개와 수수료 고지가 들어간
`/about` 페이지는 이미 있습니다.
