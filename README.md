# 🔥 핫딜 모아보기 — 사이트 + 오픈채팅 운영

토스쇼핑 쉐어링크 · 쿠팡 파트너스 링크를 올리는 **내 핫딜 채널**입니다.
실시간 알림은 **카카오톡 오픈채팅방**에서 하고, 이 사이트는 최근 딜을 등급·카테고리로
모아 보는 "오늘 핫딜 모아보기" 페이지입니다. 쉐어링크 "활동 채널 인증"에 제출할 주소가 되고,
딜을 올리면 오픈채팅방에 붙여넣을 문구까지 만들어 줍니다.

- **`index.html`** — 딜 목록. 위에서부터 수수료 고지 띠 → 남색 헤더(≡ 메뉴) → 등급 칩(🔥 개수) → 카테고리 칩 →
  최신 등록순 최대 50개 카드(상품 이미지 · N일 전 · 상품명 · 등급 + 지금 가격 · 취소선 평소가, 카드 전체가 링크) →
  화면 아래 고정 **「실시간 핫딜알림방 입장하기」** 버튼. 검색·정렬 같은 조작은 없고 상품만 보입니다
- **`about.html`** — 채널 소개 · 알림방 링크 · 등급 안내 · 수수료 고지. 인증 심사에서 이 페이지를 봅니다
- **`add.html`** — 컴퓨터에서 딜 하나를 폼으로 채우면 붙여넣을 코드와 카톡 문구를 만들어 주는 도구
- **`data/site.js`** — 채널 이름 · **오픈채팅 링크** · 등급표 · 최대 개수 · 고지 문구. 설정은 전부 여기
- **`data/deals.js`** — 딜 목록. 실제로 고치는 파일은 거의 이것 하나입니다
- **`.github/`** — 이슈에 쉐어링크만 넣으면 딜이 자동으로 올라가는 폼과 워크플로

빌드 도구, 서버, 데이터베이스가 없습니다. HTML 파일을 그대로 올리면 끝입니다.

## 1. 처음 한 번만 — 오픈채팅방과 연결하기

1. **오픈채팅방 만들기** — 카톡 → 오픈채팅 → 만들기 → 그룹 채팅방 → 이름 정하기 →
   방에 들어가서 오른쪽 위 ≡ → **링크 공유 → 링크 복사** (`https://open.kakao.com/o/...`)
2. `data/site.js`를 열어 아래 두 줄을 내 것으로 고칩니다.

   ```js
   name: "오늘의 핫딜",          // 오픈채팅방 이름과 같게
   openChatUrl: "",             // 1번에서 복사한 링크. 비우면 입장 버튼이 안 보입니다
   ```

3. `data/deals.js`의 **샘플 딜 3개를 지웁니다** (링크가 `example.com`이라 눌러도 아무 일이 없고,
   카드에 "샘플" 표시가 붙어 있습니다).

`disclosure`(수수료 고지)는 **지우지 마세요.** 수수료를 받는 링크라는 사실을 눈에 띄게
알리는 것은 공정거래위원회 추천·보증 심사지침상 의무이고, 쉐어링크 채널 인증에서도 봅니다.
사이트 맨 위 띠 · 하단 · 카톡 문구 세 군데에 자동으로 들어갑니다.

## 2. 딜 올리기 — 폰에서, 코드 없이

**GitHub 이슈에 쉐어링크만 붙여넣으면** 사이트가 알아서 갱신됩니다.

1. 저장소 → **Issues → New issue → 「딜 올리기」**
2. 쿠팡·토스 **공유하기**로 복사한 내용을 그대로 붙여넣고, 지금 가격과 **등급**만 고르면 됩니다
   (상품명은 붙여넣은 글에서 갈라내고, 사진은 링크에서 읽어 봅니다)
3. 1분쯤 뒤 `data/deals.js`가 자동으로 커밋되고, 이슈 답글로 **오픈채팅방에 붙여넣을 문구**가 옵니다.
   그 문구를 복사해서 방에 올리면 끝. 이슈는 자동으로 닫힙니다.

딜이 끝나면 **「딜 마감」** 이슈에 상품명 일부만 적으면 목록에서 빠집니다 (파일에는 기록으로 남습니다).
사이트의 `딜 올리기` 페이지 위쪽 링크로도 두 폼에 바로 갈 수 있습니다.

카톡 문구는 이런 모양입니다:

```
🔥🔥 대박
💎 [토스] 한돈 냉장 삼겹살 구이용 1kg
💰 14,900원 (평소 24,900원, 40%↓)
📝 냉장 삼겹 1kg 이 가격이면 바로 담으세요
👉 https://toss.im/_m/...

- 가격·혜택은 게시 당시 기준이며 실시간 변경될 수 있습니다.
- 안내된 가격과 다를 경우 구매를 권하지 않습니다.
* 이 게시물은 쉐어링크 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
```

알아 두실 것:

- **저장소 주인이 연 이슈에만 반응합니다.** 공개 저장소라 누구나 이슈를 열 수 있는데,
  이 조건이 없으면 남의 쉐어링크가 내 사이트에 올라갑니다 (`.github/workflows/deal.yml`).
- **상품 사진은 링크에서 읽어 옵니다.** 판매 페이지의 미리보기 태그(`og:image`·`twitter:image`·
  `link rel=image_src`·JSON-LD)를 차례로 훑고, 짧은 링크가 중간 페이지를 돌려주면 한 번 더 따라갑니다.
  그래도 못 읽으면 카드에 판매처 아이콘이 들어갑니다 — 그때는 **이슈에 상품 사진을 그대로 첨부**하세요.
  붙여넣기 칸에 사진을 끌어다 놓으면 그 사진을 씁니다.
- 상품명도 못 찾으면 실패로 끝내지 않고 "직접 적어 달라"고 답글이 옵니다.
- **쉐어링크를 만드는 일 자체는 자동화할 수 없습니다.** 토스는 공개 API가 없어서
  앱에서 상품 공유 → 링크 복사까지는 사람이 해야 합니다. 그 뒤가 전부 자동입니다.
- **오픈채팅방에 자동으로 쏘는 것도 불가능합니다.** 카카오는 오픈채팅에 봇이 글을 쓰는 공개
  API를 주지 않습니다. 문구를 만들어 주는 데까지가 한계이고, 붙여넣기는 사람이 합니다.

## 3. 등급 — 🔥 개수가 곧 등급

| 등급 | 뜻 |
|---|---|
| 🔥🔥🔥 무지성급 | 역대 최저가. 고민할 필요 없음 |
| 🔥🔥 대박 | 평소보다 크게 쌈 |
| 🔥 추천 | 가격 괜찮고 살 만함 |

등급 칩이 한 줄에 들어가도록 세 단계로 둡니다. 늘리면 줄이 넘어갑니다.

이름과 설명은 `data/site.js`의 `grades`에서 바꿉니다. 이슈 폼의 등급 선택지
(`.github/ISSUE_TEMPLATE/deal-add.yml`)는 🔥 개수만 읽으므로, 이름을 바꾸면 그쪽 글자도 같이 맞춰 두세요.
등급을 고르지 않은 딜은 배지 없이 올라갑니다.

## 3-1. 카테고리

목록 화면의 카테고리 칩은 `data/site.js` 의 `categories` 가 정합니다. 딜이 하나도 없어도 늘 보입니다.

```js
categories: ["고기·메인반찬", "간식·음료", "생활용품·기타"],
```

**이슈 폼(`.github/ISSUE_TEMPLATE/deal-add.yml`)의 선택지와 같게 두세요.** 한 줄에 들어가도록 서너 개로
유지하는 편이 좋고, 넘치면 옆으로 밀립니다. 여기 없는 카테고리로 올린 딜은 칩이 자동으로 하나 더 생기니
목록에서 사라지지는 않습니다.

## 4. 카톡에서 열릴 때

- 방에 올린 사이트 링크는 **카톡 인앱 브라우저**에서 열립니다. 거기서는 토스·쿠팡 앱으로 넘어가는
  링크나 복사가 막힐 때가 있어서, 사이트가 카톡 안에서 열린 것을 감지하면 위쪽에
  **"다른 브라우저로 열기"** 안내와 버튼을 띄웁니다 (카톡이 지원하는 `kakaotalk://web/openExternal` 주소).
- 사이트를 고쳤는데 카톡 링크 미리보기가 옛날 것이면 카카오가 미리보기를 캐시한 것입니다.
  [카카오 OG 캐시 초기화 도구](https://developers.kakao.com/tool/clear/og)에 주소를 넣거나,
  링크 뒤에 `?v=2` 처럼 번호를 붙여 새 주소로 공유하면 됩니다.

## 5. 인터넷에 올라가는 두 주소

`main`이 바뀌면 두 곳에 자동으로 올라갑니다. 둘 다 무료이고 내용은 같습니다.

| 주소 | 누가 올리나 |
|---|---|
| https://todays-hotdeal.pickuping.workers.dev | **Cloudflare Workers** — 대시보드가 이 저장소를 직접 지켜보다가 `npx wrangler deploy` 실행 |
| https://cyc53233-coder.github.io/me/ | GitHub Pages — 저장소 설정에 켜져 있음 |

카톡 방에는 짧은 **Workers 주소**를 올리는 편이 깔끔합니다. 고친 게 안 보이면 **Ctrl+Shift+R** 로 새로고침하세요.

이슈로 딜을 올리면 `data/deals.js`가 `main`에 커밋되고, 두 주소가 1~2분 안에 알아서 갱신됩니다.
손으로 파일을 올릴 일은 없습니다.

### Cloudflare 쪽에서 바꾸고 싶을 때

dash.cloudflare.com → Compute(Workers) → **todays-hotdeal** 로 들어가면 됩니다.

- **배포 기록·실패 로그** — Deployments 탭. 빨간 줄이 있으면 눌러서 로그를 봅니다
- **주소 바꾸기** — 저장소의 `wrangler.jsonc` 에서 `name` 을 바꾸고, 대시보드 프로젝트 이름도 같게 맞춥니다.
  둘이 다르면 배포가 이름 불일치로 실패합니다
- **산 도메인 붙이기** — 그 워커 → Settings → Domains & Routes

무엇이 올라가는지는 `.assetsignore` 가 정합니다. 사이트 파일(HTML 3개 · `assets/` · `data/`)만 나가고
가계부(`ledger/`), `v2/`, `pricewatch/`, 스크립트, 워크플로는 올라가지 않습니다.

### 워크플로 「Cloudflare Workers 배포」는 왜 늘 "건너뜀"인가

`.github/workflows/cloudflare.yml` 은 대시보드를 쓰지 않고 GitHub Actions로 배포하는 **다른 길**입니다.
지금은 대시보드가 배포를 맡고 있어서, 이 워크플로는 시크릿이 없는 채로 매번 "건너뜀"으로 끝납니다. 정상입니다.
**시크릿(`CLOUDFLARE_API_TOKEN`·`CLOUDFLARE_ACCOUNT_ID`)을 넣지 마세요** — 넣으면 두 곳에서 같은 워커에
배포하게 됩니다. 대시보드 연결을 끊었을 때만 쓰는 예비 수단입니다.

## 6. 쉐어링크 활동 채널로 등록하기

토스 앱 → 쉐어링크 → **활동 채널을 알려주세요** 화면에서 5번의 주소 중 하나를 넣고
`채널 추가` → `제출`을 누릅니다.

인증은 "이 사람이 실제로 상품을 소개하는 채널을 운영하는가"를 보므로, 제출 전에
**딜 몇 개는 실제 링크로 올려두는 편이 안전합니다.** `about.html`에 채널 소개와
수수료 고지가 이미 들어 있으니 그대로 두면 됩니다. 오픈채팅방 링크도 같이 제출할 수 있습니다.

## 7. 내 컴퓨터에서 미리 보기

파일을 더블클릭해도 열리지만, 실제 주소와 똑같이 보려면:

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
