# 🔥 핫딜 큐레이션 사이트

토스쇼핑 쉐어링크 · 쿠팡 파트너스 링크를 올리는 **내 채널 웹사이트**입니다.
쉐어링크 "활동 채널 인증"에 제출할 주소가 되고, 딜을 올리면 카톡방에 붙여넣을 문구까지 만들어 줍니다.

- **`index.html`** — 딜 목록. 검색 · 카테고리 · 최신순/할인율순 · 마감 딜 보기
- **`about.html`** — 채널 소개와 수수료 고지. 인증 심사에서 이 페이지를 봅니다
- **`add.html`** — 딜 하나를 폼으로 채우면 붙여넣을 코드와 카톡 문구를 만들어 주는 도구
- **`data/site.js`** — 채널 이름·소개·연락처 설정
- **`data/deals.js`** — 딜 목록. 실제로 고치는 파일은 거의 이것 하나입니다

빌드 도구, 서버, 데이터베이스가 없습니다. HTML 파일을 그대로 올리면 끝입니다.

---

## 1. 처음 한 번만 — 내 채널로 바꾸기

`data/site.js`를 열어서 채널 이름, 소개, 연락처를 내 것으로 고칩니다.

```js
name: "무지성 핫딜",
tagline: "하루 종일 뒤져서 진짜 싼 것만 올립니다",
contact: "내메일@example.com",
```

`disclosure`(수수료 고지)는 **지우지 마세요.** 수수료를 받는 링크라는 사실을 눈에 띄게
알리는 것은 공정거래위원회 추천·보증 심사지침상 의무이고, 쉐어링크 채널 인증에서도 봅니다.

그다음 `data/deals.js`에 들어 있는 **샘플 딜 3개를 지웁니다**
(링크가 `example.com`이라 눌러도 아무 일이 없고, 카드에 "샘플" 표시가 붙어 있습니다).

## 2. 딜 올리기

1. `add.html`을 엽니다 (파일을 더블클릭해도 열립니다).
2. 상품명, **내 쉐어링크**, 지금 가격, 평소 가격을 채웁니다.
3. **1번 상자의 코드를 복사**해서 `data/deals.js`의 `window.DEALS = [` 바로 아랫줄에 붙여넣습니다.
4. 저장하고 push 하면 사이트에 올라갑니다.
5. **2번 상자의 카톡 문구를 복사**해서 오픈채팅방에 그대로 붙여넣습니다.

목록 화면의 카드마다 있는 💬 버튼도 같은 카톡 문구를 복사해 줍니다.

딜이 끝나면 지우지 말고 `ended: true` 한 줄만 추가하세요. 마감 표시로 남아서
"이 채널이 얼마나 오래 굴러왔는지"가 기록으로 쌓입니다.

## 3. 인터넷에 올리기 (GitHub Pages, 무료)

1. 이 브랜치를 `main`에 머지합니다.
2. GitHub 저장소 → **Settings → Pages**
3. Source를 **Deploy from a branch**, 브랜치는 **`main` / `(root)`** 로 두고 Save
4. 1~2분 뒤 주소가 나옵니다: `https://<내아이디>.github.io/me/`

주소를 바꾸고 싶으면 저장소 이름을 바꾸거나(`me` → `hotdeal`), 도메인을 샀다면
Pages 설정의 Custom domain에 연결하면 됩니다.

## 4. 쉐어링크 활동 채널로 등록하기

토스 앱 → 쉐어링크 → **활동 채널을 알려주세요** 화면에서 3번의 주소를 넣고
`채널 추가` → `제출`을 누릅니다.

인증은 "이 사람이 실제로 상품을 소개하는 채널을 운영하는가"를 보므로, 제출 전에
**딜 몇 개는 실제 링크로 올려두는 편이 안전합니다.** `about.html`에 채널 소개와
수수료 고지가 이미 들어 있으니 그대로 두면 됩니다.

## 5. 내 컴퓨터에서 미리 보기

파일을 더블클릭해도 열리지만, 실제 주소와 똑같이 보려면:

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

  하단 안내 문구를 지우지 마세요.

  반드시 내 계정에서 만든 링크를 넣으세요.
