# 학습 계획표

A4 가로로 뽑아 쓰는 수험 계획표입니다. [`index.html`](./index.html)을 열면 화면에서 고쳐 쓰고
바로 인쇄할 수 있고, [`학습계획표.pdf`](./학습계획표.pdf)는 처음값으로 뽑아 둔 인쇄본입니다.

인쇄하면 **계획표 한 장 + 달력 한 장**이 나옵니다.

- **첫째 장 — 학습 계획표.** 시험 두 개의 D-day가 날마다 자동으로 채워지고,
  그 아래 날짜·요일·휴식 칸, 과목마다 적는 칸, 맨 밑에 과목별 메모.
- **둘째 장 — 달력.** 그달 전체를 크게 펼쳐 칸마다 그날 할 일을 적습니다.
  계획 기간에 든 날은 색이 깔리고, 칸마다 그날 기준 D-day가 붙습니다.
  기간이 두 달에 걸치면 달마다 한 장씩 나옵니다(사흘도 안 걸친 달은 뺍니다).

고친 값, 손으로 채운 칸, 스티커 자리는 모두 **그 브라우저에 저장**됩니다.

## 조작줄

### 기간과 시험

| 칸 | 하는 일 |
| --- | --- |
| 기간 시작 · 일수 | 표에 깔릴 날짜. **←/→** 로 다음 기간 표를 새로 뽑습니다 |
| 시험 1 · 2 | 카운트다운 두 개의 이름과 시험일. 날짜를 넣으면 D-day가 전부 다시 계산됩니다 |

**산안산기 시험일은 비워 두었습니다.** 원서 접수 일정이 나오면 넣어 주세요.
공무원은 원본 계획표의 `D-346`(2026-07-08 기준)에서 역산한 **2027-06-19**를 넣어 두었으니,
실제 시험일이 다르면 고치면 됩니다.

### 양식

| 칸 | 하는 일 |
| --- | --- |
| 과목 | 이름을 고치고, `✕`로 빼고, `+ 과목`으로 늘립니다 (최대 5) |
| 과목당 칸 | 과목마다 적는 줄 수. 과목 수에 맞춰 고를 수 있는 값이 줄어듭니다 |
| 메모 줄 | 과목별 메모 한 칸의 괘선 수 (1~3) |
| 휴식 / 메모 줄 | 표 위쪽 휴식 칸을 넣거나 뺍니다 |
| 달력에 D-day | 달력 칸마다 붙는 D-day 숫자를 넣거나 뺍니다 |
| 달력 달 추가 | 계획 기간 밖의 달도 한 장 더 뽑습니다 |

칸 높이는 **양식에 맞춰 자동으로 다시 계산**됩니다. 과목이나 줄을 늘리면 한 칸이 얇아지되
언제나 한 장(190mm) 안에 들어맞습니다. 그래서 `과목 × 칸`은 12개까지만 고를 수 있습니다.

### 스티커

밤톨이 사진 세 장에서 배경을 지우고 다이컷 흰 테두리를 둘러 만든 스티커 세 종
(**빼꼼**·**식빵**·**얼굴**)과 **글자** 스티커가 있습니다.

- **붙이기** — 팔레트에서 고르면 지금 보고 있는 장 한가운데에 붙습니다
- **옮기기** — 끌면 됩니다. 방향키로 미세 조정(`Shift`와 함께 누르면 크게)
- **크기 · 각도 · 삭제** — 누르면 위에 단추가 뜹니다. 모서리 점을 끌어도 크기가 바뀝니다
- **글자 고치기** — 글자 스티커를 두 번 누릅니다
- **처음값** — `스티커 처음값`을 누르면 원래 자리로 돌아갑니다

자리는 종이 대비 비율(%)로 저장해서, 화면에서 본 위치가 인쇄에서도 그대로 나옵니다.
계획표 오른쪽 아래는 스티커 자리로 비워 두어, 밤톨이가 메모줄을 덮지 않습니다.

빌드 도구가 없습니다. HTML 파일 하나이고, 스티커 사진도 파일 안에 들어 있습니다.
