# 학습 계획표

A4 가로로 뽑아 쓰는 수험 계획표입니다. [`index.html`](./index.html)을 열면 바로 쓸 수 있고,
[`학습계획표.pdf`](./학습계획표.pdf)는 지금 설정으로 뽑아 둔 인쇄본입니다.

인쇄하면 **두 장**이 나옵니다.

- **첫째 장 — 학습 계획표.** 공무원·산안산기 두 D-day가 날마다 자동으로 채워지고,
  그 아래 날짜·요일·휴식 칸, 과목마다 적는 칸 3개, 맨 밑에 과목별 메모.
- **둘째 장 — 달력.** 그달 전체를 크게 펼쳐 칸마다 그날 할 일을 적습니다.
  계획 기간에 든 날은 색이 깔리고, 칸마다 그날 기준 D-day가 붙습니다.
  기간이 두 달에 걸치면 달마다 한 장씩 나옵니다(사흘도 안 걸친 달은 뺍니다).

## 고치는 곳

화면 위 조작줄에서 바꿉니다. 고친 값과 손으로 채운 칸은 그 브라우저에 저장됩니다.

| 칸 | 하는 일 |
| --- | --- |
| 기간 시작 · 일수 | 표에 깔릴 날짜. **←/→** 로 다음 2주 표를 새로 뽑습니다 |
| 시험 1 · 2 | 카운트다운 두 개의 이름과 시험일. 날짜를 넣으면 D-day가 전부 다시 계산됩니다 |
| 과목 | 과목 이름 세 개. 표와 메모칸 이름이 같이 바뀝니다 |

**산안산기 시험일은 비워 두었습니다.** 원서 접수 일정이 나오면 넣어 주세요.
공무원은 원본 계획표의 `D-346`(2026-07-08 기준)에서 역산한 **2027-06-19**를 넣어 두었으니,
실제 시험일이 다르면 고치면 됩니다.

빌드 도구가 없습니다. HTML 파일 하나이고, 밤톨이 사진도 파일 안에 들어 있습니다.
