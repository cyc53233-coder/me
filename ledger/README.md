# 다니랑 생활비 통장

둘이서 함께 쓰는 생활비통장 가계부 — 단일 파일 웹앱(`index.html`).

## 구성

- **통장 규칙** 카드가 페이지 최상단 (편집 가능, 공유 저장)
- **월별 요약 타일**: 이번 달 입금 / 지출 / 남은 돈 / 통장 누적 잔액
- **생활비 입금** 기록 (금액·내용·누가·날짜)
- **지출 내역** 기록 (금액·카테고리·내용·누가·날짜, 두 번 탭 삭제)
- **분석**: 카테고리별·사람별 지출 막대
- **자동화**
  - 결제 알림 스크린샷/영수증 **사진으로 등록** (AI 인식 → 폼 자동 채움 → 확인 후 저장)
  - **결제 문자 붙여넣기** 인식 (정규식 파싱, 실패 시 AI 폴백)
  - 가맹점 키워드·과거 기록 기반 **카테고리 자동 추천**
  - **고정지출** 템플릿 → 매달 원탭 채우기 배너
- 전체 내역 **CSV 내보내기**

## 배포 형태

claude.ai **아티팩트**로 발행해 사용한다. 아티팩트 런타임 캐퍼빌리티를 선언한다:

- `db` — 두 사람이 같은 기록을 실시간 공유 (같은 claude.ai 조직/계정으로 로그인한 뷰어끼리만)
- `sample` — 사진·문자 AI 인식 (뷰어 사용량 소모, 첫 호출 시 동의)
- `downloads` — CSV 저장

파일은 아티팩트 발행 규격(문서 스켈레톤 없이 `<title>`부터 시작)으로 작성되어 있다.
아티팩트 밖(자체 호스팅·로컬 열기)에서는 공유 저장소 대신 **기기별 localStorage**로 동작하고,
사진 인식·CSV 버튼은 자동으로 숨거나 비활성화된다.
