# 🏛️ 공공 아이디어 허브

공무원이 직접 만든 AI 도구(프롬프트, GPTs, 스킬, 매크로, 스크립트)를 모아 **누구나 가져다 쓰게 하는 카탈로그 사이트**입니다.
계정도 설치도 없이 열어서 복사하면 되고, 등록은 GitHub 이슈 폼 하나로 끝납니다.

- **`index.html`** — 도구 목록. 검색 · 업무 분야 · 도구 유형 · 최신순/이름순. 카드를 누르면 상세 창이 열리고 `#t=<id>` 링크로 공유됩니다
- **`about.html`** — 소개, 등록 절차, 이용 조건, 책임 범위
- **`submit.html`** — 등록 폼. 채우면 미리보기 카드가 그려지고, 버튼 하나로 내용이 채워진 GitHub 이슈가 열립니다 (계정이 없으면 이메일)
- **`data/site.js`** — 허브 이름 · 소개 · 연락처 · 업무 분야 · 도구 유형 · 이용 조건 목록
- **`data/tools.js`** — 도구 목록. 이슈로 등록하면 GitHub Actions 가 이 파일에 채워 넣습니다
- **`scripts/`** — 이슈 본문을 읽어 `tools.js` 에 반영하는 Node 스크립트
- **`../.github/`** — 등록 · 내리기 이슈 폼과 워크플로 (`hub.yml`)

빌드 도구, 서버, 데이터베이스가 없습니다. 저장소 루트를 GitHub Pages 로 올리면 `/idea-hub/` 에서 열립니다.

---

## 1. 처음 한 번만 — 내 허브로 바꾸기

`data/site.js` 를 열어서 이름, 소개, 저장소, 연락처를 고칩니다.

```js
name: "공공 아이디어 허브",
repo: "아이디/저장소이름",
contact: "운영자메일@example.com",
```

`.github/ISSUE_TEMPLATE/tool-add.yml` 맨 위 안내문의 사이트 주소도 내 주소로 바꿉니다.

그다음 `data/tools.js` 의 **샘플 도구 5개를 지웁니다** (링크가 `example.com` 이라 눌러도 아무 일이 없고, 카드에 "샘플" 표시가 붙어 있습니다).

`notice`(책임 범위 문구)와 `rules`(등록 시 확인 사항)는 지우지 마세요. 등록 폼의 필수 체크 항목이고, 개인정보·비공개 정보가 올라오는 것을 막는 유일한 장치입니다.

## 2. 도구가 올라오는 흐름

```
누구든 「도구 등록」 이슈를 엶
   → Actions: 형식 검사 + 미리보기 답글 + 「검토중」 라벨      (사이트에는 아직 안 올라감)
운영자가 내용을 보고 「게시」 라벨을 붙임
   → Actions: data/tools.js 에 추가 · 커밋 · 공유 문구 답글 · 이슈 닫음
```

- **누구나 등록할 수 있지만, 라벨을 붙일 권한이 있는 사람만 게시할 수 있습니다.** 이 한 단계가 검토 게이트입니다. 라벨은 첫 등록 이슈가 들어올 때 자동으로 만들어집니다.
- 게시된 뒤 내용을 고치려면 작성자가 이슈 본문을 수정하고, 운영자가 `게시` 라벨을 떼었다 다시 붙이면 됩니다. 등록일과 추천 표시는 유지됩니다.
- 닫힌 이슈는 그 도구의 **질문·의견 게시판**이 됩니다. 상세 창의 "등록 이슈에 남기기" 링크가 여기로 옵니다.

## 3. 도구 내리기 · 추천 표시

- **내리기** — 저장소 주인이 「도구 내리기」 이슈에 이슈 번호(`#12`)나 이름 일부를 적으면 `retired: true` 로 바뀝니다. 지우지 않고 "내림" 표시로 남습니다.
- **추천** — `data/tools.js` 에서 해당 도구에 `"featured": true` 를 손으로 넣습니다. 목록 맨 위에 ⭐ 로 고정됩니다.

## 4. 스크립트를 직접 돌려 보기

```sh
ISSUE_BODY="$(cat 이슈본문.md)" ISSUE_NUMBER=12 MODE=preview node idea-hub/scripts/apply.mjs
cat .hub-comment.md      # 이슈에 달릴 답글
```

`MODE` 는 `preview` · `publish` · `retire`. `publish` 는 `data/tools.js` 를 실제로 고칩니다.

## 5. 우리 기관 안에서만 쓰려면

저장소를 복제해서 `data/site.js` 만 고치면 같은 허브가 하나 더 생깁니다. 사내 GitHub Enterprise 나 내부망 정적 호스팅에 올려도 그대로 돕니다 (Pretendard 폰트 CDN 만 막히면 시스템 폰트로 대체됩니다).
