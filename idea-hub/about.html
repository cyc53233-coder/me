소개

어떤 것을 올릴 수 있나요

  • 프롬프트 — ChatGPT, Claude, Gemini 등에 붙여넣는 지시문. 카드에서 바로 복사됩니다.
  • GPTs · 맞춤봇 — 링크로 공유되는 맞춤 챗봇.
  • 에이전트 스킬 — 에이전트가 읽는 SKILL.md 같은 작업 절차 파일.
  • 스크립트 · 매크로 — 파이썬 스크립트, 엑셀 VBA, 한글 매크로. 파일은 GitHub나 드라이브에 두고 링크만 올립니다.
  • 노코드 앱 · 양식 — 설문, 자동화 흐름, 보고서 템플릿.

등록 절차

  1. 등록 페이지에서 폼을 채웁니다.이름, 한 줄 설명, 업무 분야, 사용 방법이면 충분합니다. 미리보기 카드가 바로 그려집니다.
  2. GitHub 이슈로 보냅니다.버튼을 누르면 내용이 채워진 이슈 폼이 열립니다. GitHub 계정이 없으면 이메일로 보내도 됩니다.
  3. 운영자가 확인합니다.개인정보·비공개 정보가 없는지, 링크가 열리는지 봅니다. 보통 며칠 안에 끝납니다.
  4. 사이트에 올라갑니다.이슈에 게시 라벨이 붙는 순간 자동으로 올라가고, 공유용 링크와 문구를 답글로 받습니다.

올릴 때 지켜야 하는 것

    등록 폼에서 위 항목에 체크해야 제출됩니다. 나중에라도 문제가 발견되면 도구를 내리고 기록만 남깁니다.
